# hermes-yandex-alice

Яндекс Алиса как платформа шлюза [Hermes Agent](https://github.com/NousResearch/hermes-agent). Плагин
`kind: platform` принимает webhook приватного навыка Яндекс Диалогов, передаёт реплику в обычную сессию шлюза
(профиль задаётся `gateway.profile_routes`), озвучивает ответ агента и по просьбе присылает подробности в Telegram.

Это **диалог, а не одна команда**: после ответа сессия Алисы остаётся открытой, следующая реплика продолжает ту же
беседу Hermes с историей. Если ответ не успевает за лимитом Алисы (около 4,5 с), плагин удерживает запрос до 3,5 с,
потом предлагает подождать, спросить позже или прислать ответ в Telegram.

Статус: бета. Приватный навык, один владелец. Проверенная версия Hermes указана в [документации по совместимости](docs/compatibility.md).

## Возможности

- Голосовые ответы по частям, «дальше» читает следующую часть.
- Ожидание ответа: «подожду», «позже», «скинь ответ», «пришли в Телеграм».
- «Новый диалог» / «прошлый»: начало новой беседы или продолжение текущей.
- Подробности и внеходовые сообщения агента уходят в Telegram с подписью «Алиса:».
- Опасные команды агента подтверждаются карточкой в Telegram (механизм `approvals` Hermes), без подтверждения не
  выполняются. Голосом подтвердить нельзя.
- Состояние беседы переживает перезапуск шлюза (SQLite в `plugin_db`).
- Доступ только владельцу, секретный путь в URL, loopback-listener, ограничение частоты и дедупликация запросов.

## Быстрый старт

[Развёртывание](docs/deployment.md) описывает установку плагина, настройку профиля и HTTPS-прокси. Затем
[создайте приватный навык и проверьте его голосом](docs/yandex-dialogs.md).

## Структура репозитория

```
yandex-alice/      каталог плагина → ~/.hermes/plugins/yandex-alice
  plugin.yaml      манифест
  adapter.py       адаптер шлюза: listener, регистрация, Telegram, чтение истории
  protocol.py      протокол Диалогов, тексты, интенты (без зависимостей от Hermes)
  dialog.py        машина беседы step(state, event) (без зависимостей от Hermes)
  engine.py        исполнитель действий машины, удержание запроса, гейт хода
  entry.py         порядок проверок входящего запроса
  sends.py         правило итога хода и внеходовых отправок
  storage.py       снимок состояния в SQLite
  delivery.py      очередь доставки в Telegram
  approvals.py     книга карточек подтверждений
  history.py       чтение истории для «повтори»
  cron_guard.py    ограничения cron из голоса
tests/             unittest, checkout Hermes не нужен
compat/            тесты совместимости с настоящим Hermes (запуск вручную, `compat/README.md`)
prototypes/        пробы S2, S3, S4, S6, S6b против живого Hermes (S1, S5, S7 перенесены в `compat/`; запуск вручную)
docs/              инструкции, спецификация и результаты экспериментов
```

## Тесты

```
py -m pip install -r requirements-test.txt
py -m unittest discover -s tests
```

Python 3.11–3.14 (диапазон Hermes). CI — `.github/workflows/tests.yml`.
